Comet is open-source firmware that turns a LoRa handheld into a device you can always carry: mesh messages, offline maps, books and audiobooks, and soon text messages and calls over the built-in modem.

Install Comet See the roadmap

What Comet does today

Built on MeshCore. Everything below works on the LilyGo T-Deck Max, most of it on the T-LoRa Pager.

Mesh messaging
Chats, channels and contacts on MeshCore, with the companion app over Bluetooth, Wi-Fi or USB.
Maps
Offline map tiles on the SD card, your position from the GPS, the nodes you have heard.
Books and audiobooks
An EPUB reader, and an Audiobookshelf client that streams, downloads for offline listening, or plays folders of MP3s from the card.
Files over USB
Browse, upload and download the SD card from a browser over the cable.
Made for e-paper
Contrast and refresh tuned for the Max's e-paper, with keyboard, touch, haptics and audio.

Install

Comet is in testing: the current build is a test build for the T-Deck Max. The installer runs in Chrome or Edge on a computer.

  1. Connect the T-Deck Max

    Plug it into your computer with a USB-C data cable. If it does not show up in the next step, hold the BOOT button while you plug it in.

  2. Install

    Choose the device from the list. An existing install keeps its settings, contacts and chats; a new one asks whether to erase the device first.

    This browser cannot talk to USB devices. Open the page in Chrome or Edge on a computer, or use esptool below. The installer needs the page over HTTPS: open https://cometmesh.org.

  3. Or with esptool

    Download comet-tdeck-max.bin and write it over an existing install; settings, contacts and chats stay:

    esptool --chip esp32s3 --port <PORT> --after watchdog-reset write-flash 0x10000 comet-tdeck-max.bin

Once Comet runs, it updates itself over Wi-Fi: About, then Install update. Test builds come with About, Get test builds.
