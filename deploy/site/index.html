Comet is open-source firmware that turns a LoRa handheld into a device you can always carry: mesh messages, offline maps, books and audiobooks, and soon text messages and calls over the built-in modem.

Install Comet See the roadmap

What Comet does today

Built on MeshCore. Everything below works on the LilyGo T-Deck Max, most of it on the T-LoRa Pager.

Mesh messaging
Chats, channels and contacts on MeshCore, with the companion app over Bluetooth, Wi-Fi or USB.
Maps
Offline map tiles on the SD card, your position from the GPS, the nodes you have heard.
Books and audiobooks
An EPUB reader, and an Audiobookshelf client that streams, downloads for offline listening, or plays folders of MP3s from the card.
Files over USB
Browse, upload and download the SD card from a browser over the cable.
Made for e-paper
Contrast and refresh tuned for the Max's e-paper, with keyboard, touch, haptics and audio.

Install

There are no releases yet: builds come from GitHub Actions. A browser installer follows with the first release.

  1. Get the firmware

    Download the comet.bin for your board from the latest build on GitHub Actions.

  2. Connect the device

    Plug it in over USB. Install esptool if you do not have it.

  3. Flash it

    Over an existing install this keeps your settings, contacts and chats:

    esptool --chip esp32s3 --port <PORT> write-flash 0x10000 comet.bin
