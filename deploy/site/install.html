Install

The installer runs in Chrome or Edge on a computer. Comet is in testing, so the builds are test builds.

  1. Choose your board

    Not sure which one you have, or what works on it? See Boards.

  2. Connect it

    Plug it into your computer with a USB-C data cable. If it does not show up in the next step, hold the BOOT button while you plug it in.

  3. Install

    An existing Comet keeps its settings, contacts and chats. Coming from other firmware, erase the device first.

  4. Or with esptool

Once Comet runs, it updates itself over Wi-Fi: About, then Install update. Test builds come with About, Get test builds.

  






  

    
Comet is free software under the GPL-3.0. Flashing replaces the firmware on your device; you can always go back by flashing the original one. The installer uses esptool-js by Espressif (Apache-2.0).
