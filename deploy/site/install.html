Install

The installer runs in Chrome or Edge on a computer. Comet is in testing, so the builds are test builds.

  1. Choose your board

    Not sure which one you have, or what works on it? See Boards.

  2. Connect it

    Plug it into your computer with a USB-C data cable. If it does not show up in the next step, hold the BOOT button while you plug it in.

  3. Install

    An existing install keeps its settings, contacts and chats; a new one asks whether to erase the device first.

    This browser cannot talk to USB devices. Open the page in Chrome or Edge on a computer, or use esptool below. The installer needs the page over HTTPS: open https://cometmesh.org.

    There is no build for this board yet.

  4. Or with esptool

    Download the app image and write it over an existing install; settings, contacts and chats stay:

    esptool --chip esp32s3 --port <PORT> --after watchdog-reset write-flash 0x10000 comet-<board>.bin

Once Comet runs, it updates itself over Wi-Fi: About, then Install update. Test builds come with About, Get test builds.

Comet is free software under the GPL-3.0. Flashing replaces the firmware on your device; you can always go back by flashing the original one.
